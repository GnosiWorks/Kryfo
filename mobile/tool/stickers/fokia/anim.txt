# fokia animation, read by tool/pack_stickers.py.
#
# times in ms, angles in degrees clockwise, distances in the layer's own svg
# units, pivots in the space the selection sits in. every track starts and
# ends at rest, so the first frame is the svg and each loop closes on itself.
#
#   sticker NN name loop=MS emoji=E since=N   no loop: a still, not offered yet
#   node NAME SELECTOR @x,y pivot=P           a moving part; @x,y is the first
#                                             point of the selection, checked
#   PROP TARGET t:v t:v:ease ... ease=E       PROP x y rot sx sy scale alpha
#   clear A B px                              A and B never come closer than px
#   macros: blink look tuft breathe sway shiver pulse twinkle drop squeeze
#
# selectors: a layer id (props, props#2 for a duplicate), children by index
# (head[13:15], flipper_left[0][0][2]), root for the character, top for the
# outer transformed group. `pack_stickers.py --list NN` prints the indices.
# eases: linear hold sine out in back inout sineout sinein. a trailing !
# lets one line past the amplitude limits.
