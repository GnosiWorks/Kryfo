Une messagerie privée. Pas de numéro de téléphone, pas d’e-mail, pas de compte. Vous êtes une paire de clés générée sur votre appareil. Personne, nous compris, ne peut relier vos discussions à une identité réelle, et on ne peut vous trouver que si vous réservez un pseudo public.

Par défaut, tout passe par Tor. Le contenu est chiffré de bout en bout avec le protocole Signal. Quand un contact est hors ligne, les messages attendent sur des relais, scellés pour que le relais n’apprenne rien de qui parle ni de ce qui se dit. Jamais d’envoi du carnet d’adresses.

Fonctionnalités :

* Pas de numéro de téléphone ni d’e-mail pour s’inscrire
* Chiffrement de bout en bout (protocole Signal)
* Par défaut, tout le trafic passe par un client Tor intégré
* Distribution directe en onion, repli sur les relais quand un contact est hors ligne
* Groupes avec photos, fichiers, messages vocaux, réponses, réactions, messages épinglés et sondages
* Stickers animés envoyés sous forme de nom, aucune image ne quitte donc le téléphone
* Recherche dans toutes vos discussions, avec un index gardé dans la base de données chiffrée
* Messages éphémères : ils disparaissent après un délai choisi
* Base de données locale chiffrée et sauvegardes chiffrées
* Verrouillage de l’appli par code PIN ou biométrie, un code leurre qui ouvre un Kryfo vide, et des discussions masquées derrière leur propre code
* Effacement d’urgence qui supprime tout, y compris les médias sur le disque
* Une discussion avec la personne qui crée Kryfo, anonymement si vous le souhaitez
* 15 langues
* Aucune statistique d’usage, aucune télémétrie, aucune pub

Financement : pas de pub, pas d’investisseurs. Kryfo vit de ce que donnent ceux qui le soutiennent. Le soutien est facultatif et anonyme, et chaque fonctionnalité marche de la même façon dans les deux cas.
