# hand patches in engine/vendor

`engine/vendor/` is committed, and three files in it are not what upstream
ships. `go mod vendor` regenerates the tree and silently drops them. that
command has been run by accident in this repo before; the result builds
without a warning and the 32-bit engine never connects (tor at 0%, the app
at "connecting" forever, nothing in any log). do not run it. if the vendor
tree ever has to be rebuilt, re-apply the patches below and build with
`HALO_FULL=1 ./build.sh`, because go's build cache does not track these
headers either.

all three live under `vendor/github.com/alexballas/go-libtor/`.

## openssl: the bignum word size

`openssl_config/openssl/configuration.h` and its twin
`linux/openssl/include/openssl/configuration.h`.

upstream hard-codes `SIXTY_FOUR_BIT_LONG`. on armeabi-v7a `unsigned long`
is four bytes, so `BN_ULONG` and `BN_BYTES` disagree and every bignum
operation is wrong. the patch wraps the block: when `ARCH_ANDROID32`,
`ARCH_LINUX32` or `ARCH_WINDOWS32` is defined (go-libtor sets these per
target in `libtor/libtor_preamble.go`) it defines `THIRTY_TWO_BIT` instead,
the way go-libtor's own `openssl_config/crypto/bn_conf.h` already does.

## libevent: the generated config

`linux/libevent/include/event2/event-config.h` was generated by autoconf on
a 64-bit box: eight-byte `long`, `size_t`, `time_t`, `pthread_t` and
pointers. go-libtor has a per-target switcher in `libevent_config/`, but
that directory is not on the cgo include path, so this file always won.

the patch keeps the generated file byte for byte as `event-config.64.h`,
adds `event-config.32.h` (the same file with the five sizes set to 4 and
`_FILE_OFFSET_BITS 64`, matching go-libtor's `event-config.android32.h`),
and turns `event-config.h` into a switch on the same `ARCH_*32` defines.
the 64-bit build is unchanged.

## how to check

    cd engine
    HALO_FULL=1 ./build.sh

then on a 32-bit phone: settings, transport. tor status must leave
"starting" and bootstrap must reach 100%. a probe that prints tor's own log
over adb is described in the commit that added these patches (2026-09-13).

upstream report: alexballas/go-libtor, generated-on-64-bit headers break
32-bit targets.
